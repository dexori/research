从终端直接导入

让终端助手把选中的讨论结论保存为 Markdown，再在平台目录执行：

.venv/bin/python research_cli.py import 讨论草稿.md --kind idea --open

命令会暂存草稿并打开预览；需要登录本机平台，点击保存后才创建记录。无需模型 API Key，不会修改已有记录，也不会自动上传 GitHub。

可用 --title 指定标题，--project 指定项目 ID；运行下列命令查看项目：

.venv/bin/python research_cli.py projects

Windows 使用 .venv\Scripts\python.exe。自定义数据目录须与平台一致。草稿箱仅保存在本机；保存后的记录才可通过 GitHub 同步。
