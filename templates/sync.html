每次换电脑的流程

  1. 开始工作

    打开平台，点击同步，取回 GitHub 上的最新资料。

  2. 阅读、实验、写作

    网页保存会同时写入本机资料文件；离线也可以使用。

  3. 准备离开

    再点一次同步，看到成功提示后即可关机。

会同步什么

文献、实验、项目、想法和草稿保存为独立的 Markdown 文件。PDF、图片和结果表格保存为附件，随仓库一起上传和拉取。

登录密码、会话密钥和本机数据库保存在这台电脑上。换电脑启动后，页面内容会从仓库资料中恢复，访问密码在新电脑重新设置。

新电脑需要安装 Git 和 Python，克隆此仓库并启动平台。大数据集和权重请使用存储路径或外部链接，每次附件上传上限为 64 MB。
