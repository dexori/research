会同步什么

文献、实验、项目、想法和草稿保存为独立的 Markdown 文件。PDF、图片和结果表格保存为附件，随仓库一起上传和拉取。

登录密码、GitHub 凭据、会话密钥和本机数据库不上传。换电脑启动后，内容会从仓库资料中恢复，访问密码在新电脑重新设置。

大数据集和权重请使用存储路径或外部链接，每次附件上传上限为 64 MB。

新电脑第一次使用：完整操作步骤
  1. 安装 Git 和 Python（3.10 或更新版本）。
  2. 在浏览器登录 GitHub，打开自己的私有仓库，点击 Code → Download ZIP 并解压；不需要先在终端配置授权。
  3. 在解压后的项目目录打开终端。Linux / macOS：
    python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
    Windows PowerShell：
    py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
  4. 打开 http://127.0.0.1:8765，设置该电脑的本机访问密码。
  5. 在本页面点击「登录 GitHub」，复制授权码到 GitHub 官方页面确认。工具会自动准备；连接超时可重试。
  6. 填写同一个 HTTPS 仓库地址与分支，保存设置，再点击「同步到 GitHub」。之后开始和离开工作时各同步一次。

已有 Git 凭据的电脑也可以直接 git clone。只在新电脑首次安装时需要以上步骤，原电脑无需在线。
