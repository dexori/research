换电脑：如何连接本机 Codex

平台调用运行平台的这台电脑，不连接旧电脑。GitHub 不同步 Codex 凭据。

  1. 按 OpenAI 官方安装说明安装 CLI，确认终端能运行 codex --version。
  2. 运行 codex login 按提示登录；没有浏览器回调时可尝试 codex login --device-auth（需要账号允许设备码登录）。官方登录说明
  3. 先运行 codex 验证可以对话，然后重启平台并刷新。默认使用 ~/.codex；已有 ~/.codex-gpt2 时优先沿用它。
  4. 使用自定义 codex2 服务时，需在新电脑自行配置并登录同一服务；平台不执行 shell 别名。

启动前可设置 RESEARCH_CODEX_HOME 指定配置目录、RESEARCH_CODEX_BIN 指定程序完整路径。如果检查显示配置目录为 .codex-gpt2，登录也要使用该目录（Linux/macOS）：CODEX_HOME="$HOME/.codex-gpt2" codex login。不要把 auth.json、令牌或含密钥的配置上传 GitHub。

只检查 CLI 登录，不调用模型，不验证网络或额度。
